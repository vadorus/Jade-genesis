# Jade Genesis 0.1.14 — Adaptive Brain Routing

## Ce que Jade apprend réellement

Cette étape transforme Runtime Eval en expérience utilisable par le routeur cognitif. Chaque exécution `brain_chat` réellement tentée enregistre désormais le profil cognitif demandé (`FAST`, `GENERAL`, `REASONING`, `CODE`, `CRITIC`) avec le nœud, le modèle réellement utilisé, le succès ou l'échec, la durée, le débit et le fallback.

Le routeur combine ensuite deux sources :

1. un **prior matériel** calculé à partir de la télémétrie et des ressources du nœud ;
2. un **posterior d'expérience** calculé à partir des exécutions réelles du même profil sur ce nœud.

Avant le minimum de preuves compilé dans `SafetyPolicy`, l'expérience ne modifie pas le routage. Sa confiance augmente progressivement et son influence reste bornée par une limite non évolutive.

## Ce que cette version n'apprend pas encore

0.1.14 apprend la **fiabilité opérationnelle** d'un profil sur un nœud : disponibilité, réussite technique, latence, débit et fallback. Elle ne sait pas encore mesurer de façon fiable si une réponse était intellectuellement meilleure, plus vraie ou plus utile à l'utilisateur.

La qualité sémantique nécessitera un signal séparé : validation utilisateur, critique indépendante, tests vérifiables et/ou résultat réel de la tâche. Ce signal sera nécessaire avant de laisser Jade apprendre qu'un modèle est meilleur sur un sujet simplement parce qu'il répond plus vite.

## Sécurité

- aucun téléchargement automatique de modèle ;
- aucune mutation automatique de poids ;
- aucun changement automatique de privilèges ;
- aucun modèle ne devient l'identité de Jade ;
- aucun échec d'admission Resource Lease n'est compté comme échec du cerveau ;
- l'influence du posterior est bornée ;
- les anciennes observations sans profil restent lisibles et n'influencent pas un profil spécifique.

## Suite

La prochaine couche doit ajouter un **Outcome / Quality Learning** : Jade devra associer aux conversations des résultats observables, retours utilisateur, corrections, critiques et tests afin d'apprendre progressivement quels cerveaux et quelles stratégies donnent les meilleures réponses par domaine, pas seulement les plus rapides.
